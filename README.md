# Herr Systems Templates

A responsive one-page local-business homepage template for web design, web development, managed hosting, and practical agentic setups. It blends the friendly, high-contrast energy of Dollar Menu Developers with a restrained retro-terminal system aesthetic.

## Run locally

```bash
python3 -m http.server 8094 --bind 0.0.0.0 --directory .
```
